# 视频评审器基准数据集

在没有人工标注的情况下，用**构造法**验证 `video_review.py`（deepseek-flash 评审器）：先写合格的基准样本，再用程序定向注入已知缺陷，"注入了什么"就是标准答案。

## 组成（420 例）

| 关卡 | 每个行业的用例 | 合计 | 输入 |
|---|---|---|---|
| 创意 | 基准 1 + 红线 3 + 质量 8 + 不变性 2 | 112 | 创意 brief + 提案（Markdown） |
| 分镜 | 基准 1 + 红线 5 + 质量 8 + 不变性 2 | 128 | 分镜表 + 参考创意 |
| 资产 | 基准 1 + 红线 4 + 质量 4 + 不变性 1 | 80 | 4 张示意图 + 资产清单 + 分镜 + 品牌规范 |
| 成片 | 基准 1 + 红线 3～4 + 质量 8 | 100 | 动态分镜预演 MP4 + 字幕 + 分镜 |

8 个行业：饮料、美妆、在线教育、汽车、手游、金融理财（B 站横屏）、母婴、消费电子。
**开发集** S01–S02 用于调 rubric；**测试集** S03–S08 只用于报告结果，不能根据它改 rubric。

## 标签来源与可信度

| 标签 | 来源 | 可信度 |
|---|---|---|
| 红线应命中 | 定向注入（极限词、功效断言、未授权 IP、危险行为、AI 标识缺失、黑场/冻结、授权缺失等） | 高 |
| 基准无红线 | 基准样本经禁用词自动校验 + 人工撰写 | 高 |
| 目标维度应降分 | 定向注入单一缺陷（Logo 开场、无 CTA、字段缺失、越轴、响度异常等） | 高（只判断方向，不规定绝对分数） |
| 不变性 | 只改格式或追加无信息套话 | 高 |
| 基准应通过 | 专家先验 | 中，需人工标注确认 |

**局限**：资产图和成片是低保真示意稿，绝对分数不能代表真实画质，只看红线和相对变化；构造的缺陷比真实缺陷更"干净"，测试集表现是评审器能力的上限估计。

## 用法

```bash
python build_dataset.py                                   # 生成 dataset/（约 25 分钟，成片渲染占大头）
python run_benchmark.py --name test_v1 --split test       # 测试集评测，结果缓存，可断点续跑
python run_benchmark.py --name stab --split test --runs 3 --variants base inv_fluff   # 稳定性
python human_agreement.py export --n 12                   # 导出待人工标注表
python human_agreement.py agree --run test_v1             # 人工 vs 评审器一致性（κ）
```

## 迭代记录

| 轮次 | 改动 | 结果 |
|---|---|---|
| smoke_S01 | 初版 | 资产缺陷灵敏度 25%；成片基准误报冻结帧红线 |
| dev_v2 | 示意稿评审说明；A4 加"逐字核对品牌名"；动态配乐 | 资产灵敏度 75%；成片基准不再误报；整体通过率 91% |
| dev_v3 | 修正基准资产错误（产品名截断、角色与分镜不符）；冻结帧说明；低分辨率目标维度含 V8 | 整体通过率 93%；四关基准误报 0%；成片红线召回 100%、灵敏度 94%；资产仍漏"产品名错字"红线（S01 在 A4 证据里已指出"青氧"但未升级为 R2，S02 未发现），资产顺序打乱时总分波动 0.35–0.55 |
